# Python-CLI-Application-Design-and-Implementation
Python CLI To-Do app: add, list, edit, complete, delete, filter, search tasks. Each task has title, description, due date, priority, category, status. Saved in tasks.json. Modular design: models.py (Task), storage.py (file I/O), manager.py (logic), cli.py (menu). Uses only standard libs. Shows OOP, error handling, input validation, documentation.
